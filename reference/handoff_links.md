# Copy pages for the scripts

The file card in chat cuts off after about 150 lines, so each script has a page with a working
copy button. Each page also carries the paste instructions and what to check after the run.

| Script | What it is | Page |
|---|---|---|
| `pine/l2l.pine` | M7 v0.1, the method as described. Frozen: every later run is judged against it. | <https://claude.ai/artifact/7nqowDwxKXusmXfLtXr7yP> |
| `pine/l2l_m8.pine` | M8 v0.1, the trade in his shape: resting entry, no score gate, exit when the level gives way. | <https://claude.ai/artifact/QXDv1nywdXej1e3Cdzmv5S> |
| `pine/l2l_m9.pine` | M9 v0.1, the source method on its own: his levels, his clock, supply and demand, the VIX and big tech, the volume split. | <https://claude.ai/artifact/C5dxsBBCQk9FLMmT4xyT7L> |
| `pine/l2l_m10.pine` | M10 v0.1, M9 with no target: the trade runs until a candle closes back through the last level it cleared. | <https://claude.ai/artifact/HkK1gHvo4DZoiRFhBZncYF> |
| settings | The thirteen switches that turn M8 into his level set by hand (superseded for M9, which ships with them). | <https://claude.ai/artifact/7gZmuLRsg12bdgRkP9tTFv> |

All four strategies can sit on one chart at once: the titles differ, so TradingView keeps them
apart and each gets its own tab in the Strategy Tester.
