# trading-stuff

Level-to-Level (L2L): a key-level bounce-and-break strategy for NQ/MNQ futures (and other
symbols), written for TradingView Pine Script v6.

Status: **planning**. No code yet.

- `docs/PLAN.md` is the design: what gets built, module by module, with defaults and milestones.
- `docs/DECISIONS.md` is the list of open questions, each with a recommended default. Answer it first.

Once code starts, the script lives in `pine/`, reference material in `reference/`, and any offline
statistics work in `research/`.
